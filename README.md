# 세이프키 — 비밀번호 보안 도구

강도 검사, 안전한 비밀번호 생성, 유출 여부 확인을 제공하는 React + Vite 웹앱입니다. 비밀번호는 브라우저에서만 처리하며 저장하지 않습니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 보안 설계

- 강도 검사는 입력 중 브라우저에서만 실행합니다.
- 생성기는 `crypto.getRandomValues()`를 사용하며 선택한 문자 종류를 각각 포함합니다.
- 유출 확인은 브라우저에서 SHA-1을 계산한 뒤 해시 접두사 5글자만 HIBP Pwned Passwords API로 요청합니다. 전체 해시의 나머지 부분과 응답 대조는 브라우저에서 처리합니다.
- 요청에 `Add-Padding: true`를 포함해 응답 크기를 통한 추측을 어렵게 합니다.
- 비밀번호를 `console.log`나 `localStorage`에 기록하지 않습니다.
- k-익명성은 완전한 익명이 아닙니다. API 서버는 접두사 외에 요청자의 IP 주소와 요청 시각을 볼 수 있습니다.

## Network 탭 확인

유출 확인 버튼을 누르면 Network 탭의 요청 URL은 다음 형식입니다.

```text
https://api.pwnedpasswords.com/range/{SHA-1 해시 앞 5글자}
```

공개 예시 비밀번호 `password`로 로컬 실행 중 확인한 요청 URL:

```text
https://api.pwnedpasswords.com/range/5BAA6
```

Network 요청은 HTTP 200으로 응답했고, URL에는 SHA-1 접두사 5글자만 포함됐습니다. 실제 사용하는 비밀번호는 제출 자료나 화면 공유에 기록하지 마세요.

## 회고

- **기획:** 비밀번호 점검과 생성, 유출 확인을 한 화면에서 할 수 있는 보안 대시보드로 구성했습니다.
- **Vite 구성:** 빈 저장소에서 React + JavaScript Vite 프로젝트를 만들고, 배포 경로 호환을 위해 `base: './'`를 지정했습니다. `.env`와 `.env.*`는 `.gitignore`에 추가해 환경 변수가 실수로 커밋되지 않도록 했습니다.
- **강도 기준:** 길이와 소문자·대문자·숫자·특수문자 조합을 점수화하고, 흔한 비밀번호와 연속·반복 패턴은 강도를 제한합니다. 이 점수는 편의를 위한 브라우저 내 추정치입니다.
- **유출 확인:** 전체 SHA-1 해시는 브라우저 안에서 계산하며, API 요청에는 접두사만 포함합니다. 응답의 접미사를 대문자로 정규화해 브라우저 안에서 비교합니다.
- **AI 협업과 구현 중 어려웠던 점:** 구현을 보조받아 앱 구조와 화면을 만들고, 생성기에서 선택한 문자 종류가 모두 최소 한 번 포함되도록 처리했습니다. 편향을 줄이는 난수 인덱스 선택에도 `crypto.getRandomValues()`를 사용합니다.
